# Student Performance SQL Analysis

SQL project analyzing student academic performance, attendance, study habits, and performance categories.

## Project Overview

This project demonstrates SQL data analysis skills by creating a student database, inserting records, retrieving information, filtering data, performing aggregations, and generating analytical insights.

The project focuses on answering business-style questions using SQL queries to explore student performance patterns.


## Objectives

- Create and structure a student database table.
- Retrieve and filter student information.
- Analyze performance using aggregate functions.
- Categorize students based on exam scores.
- Evaluate relationships between attendance, study hours, and performance.
- Practice real-world SQL analysis techniques.


## Tools Used

- SQL
- PostgreSQL / SQL Database Environment
- Data Retrieval
- Data Aggregation
- Conditional Logic
- Data Cleaning Functions


## Analysis Performed

### Data Retrieval
- Selected student information by required fields.
- Filtered students based on score and attendance.
- Identified unique departments.
- Sorted students based on performance.

### Performance Analysis
- Calculated:
  - Number of students per department
  - Average scores
  - Highest scores

### Performance Categorization

Students were classified into:

- Excellent
- Good
- Needs Improvement

based on exam scores.

### Data Preparation

Applied:
- Date extraction
- Missing value handling using COALESCE
- Calculated comparison metrics
